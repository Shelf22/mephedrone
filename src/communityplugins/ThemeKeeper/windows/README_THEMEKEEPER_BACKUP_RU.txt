РЕЗЕРВНАЯ КОПИЯ VENCORD + THEMEKEEPER
=====================================

Состав:
- готовая сборка Vencord;
- пользовательский плагин ThemeKeeper;
- официальный VencordInstallerCli;
- тихий launcher для запуска Discord с автопроверкой Vencord;
- Guardian в автозагрузке Windows, который переживает обновления Discord;
- helper для создания/замены ярлыка Discord на рабочем столе;
- восстановление оригинального ярлыка Discord при удалении сборки;
- исходный код сборки без папок node_modules и .git.

Версия Vencord указана в package.json в корне архива.
Точная ревизия сборки указана в первой строке dist\patcher.js.
Проверенная совместимость: Vencord 1.15.16, commit 383409e6, 6 ноября 2026 года.
Эта проверка не обновляет сборки в ZIP из предыдущих релизов.

ВОССТАНОВЛЕНИЕ ПОСЛЕ ПЕРЕУСТАНОВКИ WINDOWS
------------------------------------------

1. Установи обычный Discord Stable и запусти его хотя бы один раз.
2. Полностью закрой Discord.
3. Распакуй ZIP в постоянную папку, например C:\Vencord-ThemeKeeper.
4. Запусти RESTORE_THEMEKEEPER.cmd.
5. Скрипт установит Vencord, создаст защищённый ярлык Discord и добавит тихий Guardian в автозагрузку Windows.
6. После запуска Discord выбери нужную тему:
   Настройки Discord -> Внешний вид -> Цветовая тема.

ThemeKeeper автоматически запомнит выбранное оформление отдельно для
каждого Discord-аккаунта и восстановит его при неожиданном сбросе.

АВТОВОССТАНОВЛЕНИЕ VENCORD ПОСЛЕ ОБНОВЛЕНИЙ DISCORD
---------------------------------------------------

Discord при обновлении создаёт новую папку app-* и иногда заново записывает
ярлык Discord на рабочем столе. Поэтому одного ярлыка недостаточно.

ThemeKeeper Guardian запускается скрыто через Windows Script Host из папки
автозагрузки пользователя. Он периодически проверяет текущую версию Discord:

- если Discord обновился и патч Vencord пропал, Guardian закрывает Discord,
  заново устанавливает архивную сборку и запускает Discord обратно;
- если обновлятор заменил ярлык Discord на оригинальный, Guardian возвращает
  защищённый ярлык с той же иконкой;
- окно CMD или PowerShell при этом не появляется.

Файл START_DISCORD_THEMEKEEPER.cmd остаётся доступным как ручной launcher для
диагностики. INSTALL_DISCORD_SHORTCUT.cmd устанавливает Guardian и защищённый
ярлык отдельно, если они были удалены.

УДАЛЕНИЕ
--------

Для удаления этой сборки запусти UNINSTALL_THEMEKEEPER_BUILD.cmd. Скрипт:

1. остановит Guardian и удалит его ярлык из автозагрузки Windows;
2. закроет Discord;
3. удалит патч Vencord из Discord Stable;
4. заменит ярлык Discord на рабочем столе обратно на оригинальный:
   %LOCALAPPDATA%\Discord\Update.exe --processStart Discord.exe.

ВАЖНО
-----

После установки не перемещай и не удаляй распакованную папку: Discord
загружает Vencord непосредственно из находящейся в ней папки dist.

Это точный снимок рабочей версии на дату сборки. Если к моменту
восстановления Discord сильно изменится, старой сборке Vencord может
понадобиться обновление.

ЕСЛИ DISCORD ЗАВИС НА STARTING
----------------------------

Launcher и Guardian восстанавливают установленный патч после обновления Discord,
но не скачивают новые исходники и не пересобирают Vencord. Повторная установка
старой сборки не устраняет её несовместимость с новой версией Discord.

Для установки из исходников выполни в корне Vencord:

git pull --ff-only
corepack pnpm install --frozen-lockfile
corepack pnpm build --dev

Затем полностью перезапусти Discord. Если используется готовый архив без
инструментов сборки, нужна новая совместимая сборка архива.
